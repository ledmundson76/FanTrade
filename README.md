# FanTrade
This is my semester long project for cis3296 Software Design.

# Abstract
My project proposes a unique solution to fantasy football trading. My idea is to create a fantasy football trade calculator that calculates how good a trade is based on numerous factors. There are many similar trade calculators already out there, but my design is different. Currently, other trade calculators only calculate and evaluate the trade the players that are being traded and do not take into account the full team. This could heavily influence how good a trade actually is for someone. A trade might not be good if the full team is not taken into account. The intended users of this are everyone who plays fantasy football. This project is valuable because fantasy football is a fun activity that millions of people in America participate in every year. My project with help these people have better trades for their teams, so they can potentially do better in the league that they are in.
